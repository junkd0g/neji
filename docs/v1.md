# neji v1 (legacy)

> **v1 is frozen.** It remains installable forever, but no new features are
> planned — development happens on [v2](../README.md), which covers
> everything v1 did with a safer API. See the
> [migration table](../README.md#migrating-from-v1).

`neji` v1 is a lightweight Go package for generating structured **JSON
error responses**.

## Installing

```sh
go get github.com/junkd0g/neji
```

## Usage

```go
package main

import (
	"errors"
	"net/http"

	nerror "github.com/junkd0g/neji"
)

func HelloWorld(w http.ResponseWriter, r *http.Request) {
	err := errors.New("This is the best error message ever")
	errorResponse, _ := nerror.SimpleErrorResponseWithStatus(500, err)

	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(500)
	w.Write(errorResponse)
}

func main() {
	http.HandleFunc("/", HelloWorld)
	http.ListenAndServe(":8076", nil)
}
```

## Functions

### SimpleErrorResponseWithStatus

```go
nerror.SimpleErrorResponseWithStatus(500, err)

/*
	returns the JSON body

	{
		"message" : "Your json is wrong or something",
		"status" : 500
	}
*/
```

### SimpleErrorResponseWithCodeV2

```go
nerror.SimpleErrorResponseWithCodeV2(502, err)

/*
	returns the JSON body

	{
		"error" : {
			"status" : 502,
			"message" : "Bad gateway."
		}
	}
*/
```

Both functions return `([]byte, error)`; writing the status code and
headers is the caller's responsibility. If `err` is nil, the message is
empty.

### WrapError

```go
err := errors.New("connection timeout")
wrapped := nerror.WrapError(err, "failed to fetch data")
// "failed to fetch data: connection timeout"
```

Preserves the original error for `errors.Is` / `errors.As`. Returns nil if
`err` is nil.

### ErrInvalidParameter

```go
err := nerror.ErrInvalidParameter("user_id")
// "missing parameter user_id"
```
